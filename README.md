# Аудандық білім порталы — Laravel 13

Қазақша портал және жабық басқару панелі. HTML/CSS макетінің дизайны сақталып, деректер базаға көшірілді. Қоғамдық тіркелу және әдепкі әкімші құпиясөзі жоқ.

## Алғашқы іске қосу

PHP 8.3+, Composer 2 керек. Кеңейтімдер: mbstring, PDO SQLite немесе PDO MySQL, fileinfo, XML, ctype, tokenizer, openssl. Тесттегі фотосуреттер үшін GD керек.

```bash
composer install
php -r "file_exists('.env') || copy('.env.example', '.env');"
php artisan key:generate
php -r "file_exists('database/database.sqlite') || touch('database/database.sqlite');"
php artisan migrate --seed
php artisan storage:link
php artisan portal:create-admin
php artisan serve
```

`http://127.0.0.1:8000` ашыңыз. Кіру: `/admin/login`. Әкімшінің аты, email-і және құпиясөзі `portal:create-admin` командасында енгізіледі. npm керек емес: CSS/JavaScript `public` ішінде дайын.

## Алдыңғы нұсқаны жаңарту

База мен `storage/app` файлдарын резервке сақтаңыз. Жаңа кодты көшіргенде өз `.env`, база және жүктелген файлдарыңызды сақтаңыз. Жаңа архивте деректер базасы, `.env` және қолданушы файлдары жоқ.

```bash
composer install
php artisan optimize:clear
php artisan migrate --seed
php artisan storage:link
php artisan test
```

`migrate:fresh` қолданбаңыз: ол бар деректерді жояды. Seeder тек жетіспейтін ақпараттық беттер мен баптауларды қосады; бұрын өңделген мәтіндерді ауыстырмайды. №20 мектептің берілген атауы, мекенжайы, елді мекені, жариялау және басына бекіту күйі осы нұсқаның seed командасында жаңартылады; басқа мектептер өзгертілмейді. Алғашқы пагинация қатесі жеке `partials.pagination` шаблонымен түзетілген.

## Қоғамдық беттер

- `/` — басты бет, мектептер және соңғы жаңалықтар.
- `/schools`, `/schools/{id}` — мектептер каталогы, іздеу, түр сүзгісі, сұрыптау және мектеп карточкасы. Бекітілген мектептер алдымен, кейін жаңа мектептер көрсетіледі.
- `/news`, `/announcements`, `/documents`, `/methodology` — жарияланған материалдар, іздеу және егжей-тегжей беттер.
- `/materials/{id}/download` — тек жарияланған материалдың PDF файлын жүктеу.
- `/about` — бөлім туралы.
- `/pages/leadership`, `/pages/structure` — басшылық және бөлім құрылымы.
- `/pages/teachers`, `/pages/students`, `/pages/parents` — аудиторияға арналған ақпарат.
- `/pages/admissions`, `/pages/anticorruption` — қабылдау және сыбайлас жемқорлыққа қарсы іс-қимыл.
- `/resources` — пайдалы сілтемелер; `/contacts` — байланыс мәліметтері.

Ресми аудан атауы, басшылық, құрылым және байланыс берілмегендіктен, ол деректер ойдан қосылмаған. Ақпараттық беттерде бастапқы мәтін бар; әкімші оны ресми мәліметпен ауыстырады. №20 мектеп берілген мәліметтерімен бастапқы орнатуда қосылады. Қалған мектептер мен материалдарды әкімші енгізеді немесе жергілікті көрсетілімде `portal:demo` қосады.

## Әкімші мүмкіндіктері

Шолу панелі, мектептерді қосу/өңдеу/жою, фотосурет, жариялау; жаңалық/хабарландыру/құжат/әдістемені басқару; сурет және PDF; жариялауды болашақ уақытқа жоспарлау; ақпараттық беттерді өңдеу/жасыру; байланыс пен портал атауы; пайдалы сілтемелерді басқару; өз құпиясөзін өзгерту. Уақыт белдеуі: Asia/Qyzylorda.

Мәтіндер қарапайым мәтін ретінде сақталады және HTML-ден экрандалады. Суреттер JPG/PNG/WebP (4 МБ, ең көбі 6000×6000), PDF — 10 МБ дейін. PDF файлдары жабық дискте, жариялау тексерілетін маршрут арқылы беріледі. Фото файлдары жарияланған URL-мен қолжетімді: құпия суреттерді жүктемеңіз.

## Тексеру

```bash
php artisan test
composer validate --strict
composer audit
```

Тесттер барлық қоғамдық беттер мен әкімші формаларын, екінші бет пагинациясын, рұқсаттарды, жасырын/жоспарланған материалдарды, PDF жүктеуді, сурет жүктеу/жоюды, қауіпті файл мен URL қабылдамауды, мәтінді экрандалауды, баптаулар мен құпиясөзді тексереді. Нақты орындалған нәтижелер `VERIFICATION.md` ішінде.

## Серверге шығару

Веб-сервердің document root-ы тек `public` болсын. Apache үшін `.htaccess` берілген; Nginx үлгісі `deploy/nginx.conf` ішінде. PHP upload_max_filesize кемінде 10M, post_max_size кемінде 16M; осы шектеулерді серверде орнатыңыз.

`.env` ішінде `APP_ENV=production`, `APP_DEBUG=false`, `APP_URL=https://сіздің-доменіңіз`, `SESSION_SECURE_COOKIE=true`, `SESSION_ENCRYPT=true` орнатыңыз. HTTPS сертификатын, база және жүктелген файлдардың резервін, журналдарды бақылауды баптаңыз. Өндірістік орнату: `composer install --no-dev --optimize-autoloader`, `php artisan migrate --force`, `php artisan optimize`. Тесттерді production серверінен бұрын бөлек ортада жүргізіңіз. Алғашқы ақпараттық беттерді орнату қажет болса `php artisan db:seed --force` орындаңыз.

Қызметтік пайдаланушыға тек `storage` және `bootstrap/cache` жазуға рұқсат беріңіз; `public/storage` сілтемесі суреттерге керек. APP_KEY жаңартуға болмайды: бар сессияларды және шифрланған деректерді жарамсыз етеді. Reverse proxy болса Laravel-дің trusted proxies баптауын нақты серверге сәйкес реттеңіз.

Басты сурет архивте жергілікті сақталған (Unsplash, сыныптың иллюстрациялық фотосы). Шрифт Google Fonts-тен жүктеледі; интернетсіз жүйелік шрифт қолданылады. Мектеп пен материал суреттері жергілікті сақталады.

Жаңа мектеп әдепкіде жарияланады. Сақтағаннан кейін хабарлама мен «Сайтта көру» сілтемесі шығады. Бұрын жоба болып сақталған жазбаны `/admin/schools` тізімінде «Жариялау» батырмасымен ашыңыз. Қоғамдық каталогта сүзгіні тазалаңыз. Әкімші іздеуі атау мен елді мекенді қамтиды; қазақша бас/кіші әріп ескерілмейді. Оқушы саны белгісіз болса, бос қалдыруға болады.
